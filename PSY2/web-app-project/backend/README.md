# Backend Documentation

This is the backend part of the web-app-project, which is built using Java and Spring Boot.

## Project Structure

- **src/main/java/com/example/App.java**: The main entry point of the application.
- **src/main/resources**: Contains configuration files and other resources needed by the application.
- **src/test/java**: Contains unit tests for the Java application.
- **pom.xml**: Maven configuration file for managing dependencies and build settings.

## Getting Started

To run the backend application, ensure you have Java and Maven installed on your machine. Follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the backend directory:
   ```
   cd web-app-project/backend
   ```
3. Build the project using Maven:
   ```
   mvn clean install
   ```
4. Run the application:
   ```
   mvn spring-boot:run
   ```
